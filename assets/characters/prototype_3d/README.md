# Materiales compartidos del personaje 3D

`pixel_materials.png` contiene cuatro regiones: piel, tela, pelo y cuerda.
Se utiliza como material compartido para objetos y superficies procedurales.
El superviviente utiliza sus PNG Meshy originales y `survivor_skin.res`, con
el perfil de material descrito en `docs/MESHY_ASSETS.md`.

El acabado de los recursos nuevos debe ser pixel art de alta resolución,
con píxeles definidos y contornos finos. Mantener nearest con mipmaps.
Las reglas visuales se encuentran en AGENTS.md.
