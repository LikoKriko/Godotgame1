# bow

FBX original del usuario, sin modificaciones. Las texturas originales, el hash del ZIP, el hash del FBX y la procedencia están en `assets/models/meshy/bow/source.json`.

La carpeta `source/` queda fuera de la importación automática de Godot mediante `.gdignore`; el juego carga la malla nativa comprimida. Consulta `docs/MESHY_ASSETS.md` para regenerarla.
