# Enemigo1 — Meshy Mossclaw Boar

Modelo aportado por el usuario, que sustituye la reconstrucción procedural.

- FBX original sin modificar: `source/Meshy_AI_Mossclaw_Boar_1015190139_texture.fbx`.
- Cuatro PNG originales y recurso de ejecución: `assets/enemies/first/meshy/`.
- ZIP original: [Release modelo-enemigo1](https://github.com/LikoKriko/Godotgame1/releases/download/modelo-enemigo1/Meshy_AI_Mossclaw_Boar_1015190139_texture_fbx.zip).
- SHA-256 del ZIP: `f0af7cc7091dfa1c6219a23b6c609e695a1a7dae90206889fab21802ed4c3655`.

El FBX no trae esqueleto ni animaciones. Se ha añadido una ligadura de integración
para las acciones provisionales; no es un paquete de animaciones de Meshy.
La carpeta `source` lleva `.gdignore` para evitar importar/exportar por duplicado
el FBX de autoría. El juego carga `mossclaw_skin.res`, que conserva su geometría,
proporciones y UV. Ver `docs/YOUNG_3D.md` para reproducir la conversión.
